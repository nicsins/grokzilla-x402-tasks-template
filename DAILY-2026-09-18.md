**Price guidance**: $0.003 – $0.008 / call
**Primary use**: Cache keys, content-addressable storage, deduplication of web resources, agent URL comparison, sitemap/canonical link generation.
**Deployment**: Vercel Edge (preferred), Node on Tailscale / GitHub.
**Template path**: `url-canonicalizer/`

## Task 2: geohash-toolkit
**Description**: Encode latitude/longitude to geohash strings (configurable precision), decode back to bounding box + center, compute 8-neighbors. Fully deterministic pure JS arithmetic — no geospatial libraries.
**Price guidance**: $0.004 – $0.009 / call
**Primary use**: Spatial indexing for agents, proximity queries, location clustering, privacy-preserving location sharing, map tile keys.
**Deployment**: Vercel Edge.
**Template path**: `geohash-toolkit/`

## Task 3: slugify-toolkit
**Description**: Generate clean URL/filename-safe slugs from arbitrary Unicode text. Supports separator choice, max length, lowercasing, basic transliteration of common diacritics, collapse of whitespace/punctuation. Deterministic and pure.
**Price guidance**: $0.003 – $0.007 / call
**Primary use**: Content routing, filename sanitization, SEO-friendly paths, multi-agent document IDs, CMS-style slug generation.
**Deployment**: Vercel Edge / serverless.
**Template path**: `slugify-toolkit/`
