**Template path**: `cidr-toolkit/`

## Task 3: hash-digest
**Description**: Compute SHA-256 / SHA-512 / SHA-1 / MD5 digests of utf8 or hex input. Returns hex + base64. Input size limited to 1 MB.
**Price guidance**: $0.002 – $0.006 / call
**Primary use**: Content addressing, integrity checks before upload, cache keys, deterministic fingerprints for agent memory / RAG, compatibility with legacy systems (MD5/SHA1).
**Deployment**: Vercel Edge / serverless.
**Template path**: `hash-digest/`
