All three share the same lightweight pattern:

- Free `/catalog` + `llms.txt`
- 402 response with `PAYMENT-REQUIRED` base64 header
- `x-test-payment: true` bypass for local testing
- Env: `PAY_TO_ADDRESS`, `NETWORK=base`, `MAX_AMOUNT_ATOMIC`

## Why these three

- High agent frequency (version gates, quality filters, ID hygiene)
- Pure deterministic logic → zero variance, cheap, cacheable
- Zero heavy dependencies → tiny cold starts on Vercel Edge
- Clear value for autonomous workflows before expensive LLM or paid upstream calls
