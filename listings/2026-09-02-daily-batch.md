## Why these three

- **case-converter**: Extremely high frequency need in data pipelines, code generation, schema mapping, and agent tool-calling. Pure deterministic, zero external deps.
- **hash-generator**: Content addressing, cache keys, integrity checks, deduplication. Crypto primitives agents love and call often.
- **markdown-to-text**: Agents constantly ingest MD docs / READMEs / issues. Lightweight plain-text extraction without pulling a full MD parser.

All three follow the shared x402 stub pattern:
- HTTP 402 + PAYMENT-REQUIRED header (Base64 JSON)
- PAYMENT-SIGNATURE verification stub (x-test-payment bypass for testing)
- Free /catalog discovery endpoint
- llms.txt for AEO
- Env: PAY_TO_ADDRESS, NETWORK=base, MAX_AMOUNT_ATOMIC
