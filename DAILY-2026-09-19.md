## Task 1: ulid-toolkit
**Description**: Generate, parse, validate, and extract timestamps from ULIDs (Universally Unique Lexicographically Sortable Identifiers). Crockford Base32, pure JS + Node crypto for randomness. Fully deterministic for a given timestamp + entropy.
**Price guidance**: $0.003 – $0.008 / call
**Primary use**: Sortable unique IDs for agent logs, event streams, database keys, message ordering, time-partitioned storage, distributed system coordination.
**Deployment**: Vercel Edge (preferred), Node on Tailscale / GitHub.
**Template path**: `ulid-toolkit/`

## Task 2: email-canonicalizer
**Description**: Normalize email addresses for reliable deduplication. Lowercases, strips +tags, removes dots for Gmail/Googlemail, normalizes domain. Includes basic structural validation and batch mode (up to 50).
**Price guidance**: $0.003 – $0.007 / call
**Primary use**: Identity resolution, CRM/user matching, account linking, spam filtering, multi-agent contact deduplication.
**Deployment**: Vercel Edge / serverless.
**Template path**: `email-canonicalizer/`

## Task 3: hmac-toolkit
**Description**: Compute and verify HMAC signatures (SHA-256, SHA-512, SHA-384, SHA-1) using Node crypto. Supports hex/base64/utf8 encodings. Timing-safe verification.
**Price guidance**: $0.003 – $0.008 / call
**Primary use**: Request signing, webhook verification helpers, API authentication primitives, integrity checks between agents, payload authentication.
**Deployment**: Vercel Edge (preferred).
**Template path**: `hmac-toolkit/`
