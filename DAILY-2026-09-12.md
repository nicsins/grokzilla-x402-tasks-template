## Task 1: base58-toolkit
**Description**: Encode / decode Base58 (Bitcoin alphabet) and Base58Check (with double-SHA256 checksum). Pure JS, zero deps, fully deterministic. Handles leading zeros correctly. Supports optional version byte for address-style payloads.
**Price guidance**: $0.003 – $0.008 / call
**Primary use**: Crypto address validation/generation helpers, IPFS CID tooling, Solana/Bitcoin agent primitives, binary-to-text for agent payloads, ledger interop.
**Deployment**: Vercel Edge (preferred), Node on Tailscale.
**Template path**: `base58-toolkit/`

## Task 2: json-patch-rfc6902
**Description**: Apply RFC 6902 JSON Patch (add / remove / replace / move / copy / test) to a target document. Strict path resolution, size-guarded, pure, deterministic. Returns patched document + applied ops count.
**Price guidance**: $0.004 – $0.010 / call
**Primary use**: Agent config mutation, declarative state updates, multi-agent shared document patching, API resource partial updates without full replace, audit-friendly change application.
**Deployment**: Vercel Edge.
**Template path**: `json-patch-rfc6902/`

## Task 3: phonetic-encoder
**Description**: Encode strings with Soundex and a lightweight Double-Metaphone (primary + secondary). Deterministic, language-agnostic ASCII focus, useful for fuzzy name matching without full NLP.
**Price guidance**: $0.003 – $0.007 / call
**Primary use**: Entity resolution, name deduplication, agent search ranking, fuzzy matching pipelines, record linkage without heavy models.
**Deployment**: Vercel Edge / serverless.
**Template path**: `phonetic-encoder/`
