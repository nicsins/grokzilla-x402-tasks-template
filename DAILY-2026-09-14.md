## Task 1: levenshtein-distance
**Description**: Compute Levenshtein (and optional Damerau-Levenshtein) edit distance between two strings plus normalized similarity ratio (0–1). Pure dynamic programming, size-capped for safety. Deterministic.
**Price guidance**: $0.003 – $0.008 / call
**Primary use**: Fuzzy matching, deduplication of names/IDs, OCR/ASR error correction scoring, agent memory similarity gating, spell-check helpers.
**Deployment**: Vercel Edge (preferred), Node on Tailscale / GitHub.
**Template path**: `levenshtein-distance/`

## Task 2: phonetic-encoder
**Description**: Encode strings with Soundex (classic) and a lightweight Metaphone-style phonetic key. Useful for cross-system name matching without exact spelling. Deterministic, ASCII-focused with basic transliteration.
**Price guidance**: $0.003 – $0.007 / call
**Primary use**: People/entity matching across datasets, fuzzy search indexes, agent identity resolution, dedup of contact lists, genealogy / CRM helpers.
**Deployment**: Vercel Edge.
**Template path**: `phonetic-encoder/`

## Task 3: uri-codec
**Description**: Percent-encode / decode URI components with configurable safe characters, plus full URI component normalize (decode then re-encode). Handles UTF-8 correctly. Size-limited.
**Price guidance**: $0.002 – $0.006 / call
**Primary use**: Safe construction of query strings and path segments for agents making downstream HTTP calls, canonicalization before signing or hashing, URL hygiene in pipelines.
**Deployment**: Vercel Edge / serverless.
**Template path**: `uri-codec/`
